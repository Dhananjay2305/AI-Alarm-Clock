# AI-Alarm-Clock
This is a modern AI-powered alarm clock web app built using Vanilla JavaScript. Users can create alarms with notes, repeat days, snooze duration, and get AI voice reminders when stopping the alarm. It also includes alarm history, theme + accent customization, and works as a Progressive Web App (PWA) with offline caching.
# ⏰ AI Alarm Clock (PWA)

A modern **AI Alarm Clock Web App** with notes, repeat days, voice assistant reminders, alarm history, theme toggle, and PWA offline support.

This project is built using **HTML, CSS, and JavaScript** .


## 🚀 Features

✅ Live Digital Clock + Date  
✅ Add Alarms with Notes (Reminder Text)  
✅ Repeat Alarms on Selected Days  
✅ One-Time Alarms (Auto-disable after ringing)  
✅ Snooze System (5 / 10 / 15 mins)  
✅ AI Voice Assistant (Speaks reminder when alarm stops)  
✅ Voice Input for Notes (Mic button)  
✅ Alarm History Logs (Ringing, Snoozed, Stopped, System)  
✅ Theme Toggle (Dark / Light Mode)  
✅ Accent Color Customization  
✅ Alarm Tone Options (Soft Pulse, Digital Beep, Urgent Buzz, Mellow Chime)  
✅ Master Volume Control  
✅ Cloud Sync (Mock version using LocalStorage)
